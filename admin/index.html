VRChat 스튜디오 월드 설정 · 저장하면 월드에 5분 이내(재입장 시 즉시) 반영

1. GitHub 연결

이 페이지는 GitHub 저장소 ZunaTtang/vrchatmap 의 파일을 직접 수정합니다. Fine-grained 토큰을 만들 때 Repository access → vrchatmap 만, Permissions → Contents: Read and write 로 설정하세요. 토큰은 이 브라우저(localStorage)에만 저장되고 다른 곳으로 보내지지 않습니다. 공용 PC에서는 사용 후 "토큰 지우기"를 누르세요.

2. 공지

스폰 뒤쪽 벽의 NOTICE 보드에 표시됩니다. 줄바꿈 가능.

3. 방송 일정

SCHEDULE 보드에 위에서부터 순서대로 표시됩니다 (최대 8줄 권장).

4. 방송 없을 때 TV

TV는 처음엔 꺼져 있고, 월드 메뉴의 TV 탭에서 켜거나 YouTube 주소를 붙여넣으면 재생돼요. 켰을 때 재생할 채널은 월드에 고정되어 있어요 (바꾸려면 Unity StudioBuilder.Props.cs의 TvChannelUrls 수정 후 재업로드).

5. 벽 이미지

이미지를 고르면 2:3 비율(1024×1536 PNG)로 자동 크롭되어 바로 업로드됩니다. 월드에서는 월드 메뉴 → 방 탭의 '벽 그림 새로고침' 또는 재입장 시 반영 (GitHub Pages 반영까지 1~5분).

토큰을 입력하고 연결하세요.
